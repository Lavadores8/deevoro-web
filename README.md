# deevoro.com

Web pública de Deevoro: portada, invitación de cada club (`/club?CODIGO`) y páginas legales.

**No se edita a mano.** Las páginas se generan en el repositorio de la app
(`scripts/generar-paginas-legales.js`) y se publican con `npm run publicar-web`,
que sube lo mismo aquí y a `legal.deevoro.com` (repositorio `deevoro-legal`).

⚠️ **No borres el fichero `CNAME`.** Sin él, deevoro.com deja de funcionar.
